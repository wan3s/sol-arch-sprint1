### ИС «Алмазы»
* Отбор алмазов для цифрового аукциона (new), планирование работ, присвоение идентификаторов и подготовка ведомостей|Доработать функционал для отбора алмазов для цифрового аукциона.
* Нужно доработать функционал отбора алмазов для цифрового аукциона:
    * Для промежуточного варианта можно вести Эксель файл. Для каждого алмаза есть колонка со статусом (новый->в пути в лабораторию->в лаборатории->в пути в офис->готов к продаже->куплен->в доставке к клиенту->продан) и ссылкой на детальный отчет по каждому, который хранится в облаке. 
    * В целевом варианте сделать систему с админкой. Статусная модель алмазов такая же, как у промежуточного решения. Нужно доработать интеграцию с ИС «Аукцион» для передачи алмазов готовых к продаже.

### ИС «Аукцион»
* Публикация данных для клиентов (new), проведение аукциона.
* Нужно доработать публикация данных для клиентов:
    * В промежуточном варианте это может быть эксель файл в облаке с ссылками на детальный отчет по каждому алмазу.
    * В целевом варианте - сделать веб сайт со списком алмазов, которые будут продаваться на ближайшем аукционе с детальным отчётом из лаборатории по каждому алмазу. Возможно добавить историю прошедших аукционов со списком проданных алмазов с указанием стартовой цены и цены, за которую алмаз был продан.
